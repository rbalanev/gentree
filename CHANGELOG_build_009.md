# Changelog — gentree

Все значимые изменения в проекте документируются здесь.

Формат версий: `MAJOR_MINOR_build_XXX`
- `MAJOR_MINOR` — версия фичи (стабильная версия)
- `build_XXX` — счётчик итераций до следующей стабильной версии

---

## [0.0.1_build_009] — 2026-09-18

### Исправлено
- **Layout дерева:** переписан алгоритм позиционирования узлов — теперь дерево корректно развёрнуто, узлы не накладываются друг на друга, дети располагаются под родителями
- **Reactflow error:** убран `useReactFlow` hook из TreeView (требовал zustand provider)
- **Version:** обновлена версия во всех файлах до `0.0.1_build_009`

### Улучшено
- **MemberForm:** добавлена визуальная обратная связь при сохранении (кнопка "Сохранение...", "✓ Сохранено!")
- **Tree edges:** добавлены стрелки и цветовое кодирование (синий — отец, розовый — мать)

### Известные ограничения v0.0.1
- Нет валидации циклических ссылок в родителях
- Нет транзакций xlsx (при краше mid-write возможна потеря данных)
- Один пользователь, localhost, без авторизации

## [0.0.1_build_001] — 2026-09-18

### Добавлено
- **Backend (FastAPI)**
  - REST API для CRUD операций с участниками семьи
  - 5 endpoints: `GET /`, `GET /{id}`, `POST /`, `PUT /{id}`, `DELETE /{id}`
  - Хранение данных в `family_tree.xlsx` через openpyxl
  - Автоинкремент ID, каскадное удаление ссылок при удалении участника
  - CORS middleware для фронтенда
  - Pydantic валидация данных

- **Frontend (React + Vite)**
  - Сайдбар со списком участников
  - Модальная форма добавления/редактирования участника
  - Визуализация генеалогического древа через Reactflow
  - Карточки участников с аватарами, разделённые по полу (male/female)
  - Кастомный хук `useMembers` для загрузки данных

- **Документация**
  - `README.md` — описание проекта, запуск, структура
  - `CHANGELOG_build_001.md` — история версий
  - `.gigacode/plans/` — план реализации

### Известные ограничения v0.0.1
- Нет валидации циклических ссылок в родителях
- Нет транзакций xlsx (при краше mid-write возможна потеря данных)
- Один пользователь, localhost, без авторизации
- Опечатка в данных: "Famale" вместо "female" (исправляется на бэкенде)
