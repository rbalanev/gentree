Давай составим план для приложения версии 0.0.1a.

Суть приложения: Веб-портал для организации и хранения родословной человека, с возможность автоматического сбора информации, ручным вводом и визуализацией в виде генеологического древа всех поколений пользователя.

Для первой версии сделаем ограниченный функционал, но позволяющий понять концепцию.
Так как это веб-портал, то для начала запускать его будем на localhost без авторизации. Всё будем внедрять постепенно.
Базу данных тоже будем хранить локально. Она будет пока состоять из одного файла в формате *.xlsx с необходимыми полями доя такого проекта
