# Heritage v0.0.1 — Implementation Plan

## Концепция
Веб-портал для организации, хранения и визуализации генеалогического древа. Локальный запуск на localhost, без авторизации. Данные хранятся в `.xlsx` файле.

**Версия:** 0.0.1_build_009

## Стек
- **Backend:** FastAPI (Python) + openpyxl для работы с xlsx
- **Frontend:** React + Vite + Reactflow (визуализация дерева) + кастомный layout
- **Хранение:** `backend/data/family_tree.xlsx`

## Поля записи (xlsx sheet "People")

| Колонка | Поле        | Тип    | Описание                          |
|---------|-------------|--------|-----------------------------------|
| A         | id          | int    | Автоинкремент, первичный ключ     |
| B         | name        | str    | Имя                               |
| C         | surname     | str    | Фамилия                           |
| D         | birth_year  | int?   | Год рождения (опционально)         |
| E         | gender      | str    | male / female                     |
| F         | father_id   | int?   | ID отца (ссылка на другую запись)  |
| G         | mother_id   | int?   | ID матери (ссылка на другую запись) |
| H         | notes       | str?   | Заметки (опционально)              |

## API Endpoints

| Method | Endpoint           | Описание                  |
|--------|--------------------|---------------------------|
| GET    | /api/members/      | Получить всех           |
| GET    | /api/members/{id}  | Получить по ID          |
| POST   | /api/members/      | Создать нового          |
| PUT    | /api/members/{id}  | Обновить                |
| DELETE | /api/members/{id}  | Удалить (каскадно очистить ссылки) |

## Риски и ограничения v0.0.1

1. **Без валидации циклических ссылок** — A не может быть потомком B, если B — родитель A (не проверяется)
2. **Нет транзакций xlsx** — при краше mid-write возможна потеря данных
3. **Один пользователь** — нет блокировок файлов, нет авторизации
4. **Опечатка "Famale"** — в демо-данных xlsx, бэкенд нормализует в "female"
