# Heritage v0.0.1a — Implementation Plan

## Концепция
Веб-портал для организации, хранения и визуализации генеалогического древа. Локальный запуск на localhost, без авторизации. Данные хранятся в `.xlsx` файле.

## Стек
- **Backend:** FastAPI (Python) + openpyxl для работы с xlsx
- **Frontend:** React + Vite + Reactflow (визуализация дерева) + dagre (автолейаут)
- **Хранение:** `backend/data/family_tree.xlsx`

## Поля записи (xlsx sheet "People")

| Колонка | Поле        | Тип    | Описание                          |
|---------|-------------|--------|-----------------------------------|
| A         | id          | int    | Автоинкремент, первичный ключ     |
| B         | name        | str    | Имя                               |
| C         | surname     | str    | Фамилия                           |
| D         | birth_year  | int?   | Год рождения (опционально)         |
| E         | gender      | str    | male / female                     |
| F         | father_id   | int?   | ID отца (ссылка на другую запись)  |
| G         | mother_id   | int?   | ID матери (ссылка на другую запись) |
| H         | notes       | str?   | Заметки (опционально)              |

## API Endpoints

| Method | Endpoint           | Описание                  |
|--------|--------------------|---------------------------|
| GET    | /api/members/      | Получить всех           |
| GET    | /api/members/{id}  | Получить по ID          |
| POST   | /api/members/      | Создать нового          |
| PUT    | /api/members/{id}  | Обновить                |
| DELETE | /api/members/{id}  | Удалить (каскадно очистить ссылки) |

## Порядок реализации

### Step 1: Скейлинг проекта
1. Создать `backend/requirements.txt` (fastapi, uvicorn, openpyxl, pydantic, python-multipart)
2. `pip install -r backend/requirements.txt`
3. В `frontend/`: `npm create vite@latest . -- --template react`
4. `npm install axios reactflow @dagrejs/dagre`

### Step 2: Backend — модели и конфигурация
5. `backend/config.py` — путь к xlsx, порт
6. `backend/models.py` — Pydantic модели (MemberBase, MemberCreate, MemberUpdate, Member)

### Step 3: Backend — слой данных
7. `backend/database.py` — функции:
   - `init_db()` — создаёт директорию и xlsx с заголовками
   - `get_all_members()` — чтение всех строк
   - `get_member_by_id()` — чтение по ID
   - `create_member()` — добавление строки, авто-ID
   - `update_member()` — обновление по ID
   - `delete_member()` — удаление + очистка ссылок father_id/mother_id

### Step 4: Backend — маршруты и запуск
8. `backend/routes/members.py` — REST endpoints
9. `backend/main.py` — FastAPI app + CORS middleware + init_db при старте
10. `uvicorn main:app --reload --port 8000` (из `backend/`)
11. Тест: `GET /api/members/` → `[]`, `POST` с JSON → создание

### Step 5: Frontend — базовая структура
12. `frontend/vite.config.js` — proxy `/api` → `http://localhost:8000`
13. `frontend/src/api.js` — axios client
14. `frontend/src/hooks/useMembers.js` — хук загрузки данных
15. `frontend/src/components/Header.jsx`
16. `frontend/src/components/MemberList.jsx` — сайдбар
17. `frontend/src/App.jsx` — компоновка
18. `npm run dev` (порт 5173)

### Step 6: Frontend — формы и CRUD
19. `frontend/src/components/MemberForm.jsx` — модальная форма
20. Интеграция формы в App.jsx
21. Тест: добавление → отображение в списке → проверка xlsx

### Step 7: Frontend — визуализация дерева
22. `frontend/src/components/PersonNode.jsx` — карточка человека
23. `frontend/src/components/TreeView.jsx` — Reactflow + dagre layout
24. Интеграция TreeView в App.jsx
25. Тест: 2+ поколения, рендеринг рёбер

### Step 8: Полировка
26. `frontend/src/styles/App.css` — layout, gender-based цвета, modal
27. Edge cases: удаление родителя → очистка ссылок, root nodes
28. Проверка xlsx в Excel

## Риски и ограничения v0.0.1a

1. **Без валидации циклических ссылок** — A не может быть потомком B, если B — родитель A (не проверяется)
2. **Нет транзакций xlsx** — при краше mid-write возможна потеря данных
3. **Один пользователь** — нет блокировок файлов, нет авторизации
4. **До 3 поколений (~50 записей)** — dagre справится с layout
